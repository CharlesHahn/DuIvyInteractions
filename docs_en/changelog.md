# Changelog

## v0.1.0 (In Development)

### 2026-10-09

- **CHARMM36 real-data test case (SMO–BST)**: Added CHARMM36 real test data (Smoothened–β-sitosterol complex, CHARMM36 + CGenFF + SPC/E water, GROMACS 2018.1, source Mendeley v94vzbwzf3, Omar et al. 2020, *Data in Brief*) and 64 real-data tests (28 identifier tests + 16 per strategy two + 16 per strategy three + 4 water-bridge tests); two tpr variants are included (a water-stripped complex and a full-atom system with 63,055 SOL waters); the real-data tests now exercise all eight interaction types (the SMO–BST system contains no halogen or metal centre, so halogen bonds and metal coordination are covered by zero-result assertions)
- **Test-artifact gitignore**: Added the whole `Tests/interaction_h5data/` directory to `.gitignore` (h5/csv/xpm artifacts generated by test runs are kept out of version control)

### 2026-10-08

- **Cross-force-field water residue handling**: The `GroupIdentifier.WATER_RESIDUES` class attribute is now the single entry point (amber={SOL,HOH,WAT}, gromos={SOL}, charmm including TIP3, opls including HO4/HO5); `_find_water` / `_find_metal_binding` were switched to `self.WATER_RESIDUES` (fixing water leakage in metal-coordination); the water_bridge detectors now exclude water donors/acceptors data-driven by the water-group atom set (residue-name independent, force-field agnostic)
- **Testing convention (strategy one not run)**: per_tuple strategy files (`test_*.py` with no strategy suffix) are marked as "possibly to be dropped"; full test runs use an explicit file list covering only strategy two (`*_per_frame.py`) and strategy three (`*_two_pass.py`)

### 2026-10-06 ~ 10-07

- **GROMOS 53A6 real-data integration tests**: Identifier + strategy two/three integration tests on `gromos53a6_md.tpr` (130-residue protein + 6 ligands ZIN1–6); assertion baselines are flagged as "not yet manually verified" (except aromatic-ring and charged-residue counts cross-checked against the protein sequence)
- **GROMOS real test data**: Added `Tests/test_MD_case_gromos/`; renamed the amber real-data directory `test_MD_case` → `test_MD_case_amber`

### 2026-10-04

- **Four force-field identifiers available**: GROMOS 53A6/54A7, CHARMM36/C36m and OPLS-AA/L group identifiers merged into dev (each with synthetic SystemData unit tests); the `IDENTIFIER_CLASSES` registry is complete for amber/gromos/charmm/opls, and `dii run --ff` accepts all four force fields

### 2026-09-30

- **H-bond acceptor misclassification fix (A1, four force fields)**: Removed H-bearing non-acceptor N types (plain amides, ammonium, pyrrole N with H, guanidinium-type) from the acceptor pool, while retaining Pro N, unprotonated His pyridine-type N, neutral amines and nucleic-acid amino groups; implemented per force field via atom-type + H-neighbor counting (Amber), rtf types (CHARMM), type tables (OPLS) and structural criteria (GROMOS); the item-by-item rationale is in `doc/acceptor_identification_evidence.md`
- **Three pending items verified**: Confirmed one by one — GAFF `n2` (imine-type sp2 N, judged an acceptor per the official type table), the CGenFF `NG*` family (each type assessed against the official MASS-section annotations for retain/exclude), and nucleic-acid glycosidic `N*` (purine N9 / pyrimidine N1: three-bond in-ring sp2 N attached to sugar → excluded as non-acceptor); adversarial-review corrections applied (glycosidic `N*` excluded, CGenFF ligand tests locked); the rationale is documented in `doc/acceptor_identification_evidence.md`
- **Survey and design documents**: Multi-force-field compatibility survey (GROMOS/CHARMM/OPLS correspondence assessment), the GROMOS identifier design proposal, the competitor survey series and paper framework v1
