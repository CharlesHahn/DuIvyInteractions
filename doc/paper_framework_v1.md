## 1. 设计原则（源自对抗性审查的结论）

1. **真值唯一化**：外部化学事实（canonical SMILES / IUPAC / 文献 / 力场文档）是唯一仲裁者；ProLIF / PLIP / InterMap 只作证据，不作标准；
2. **预注册**：判例清单、仲裁标准、案例分配规则在**实验前**写死，杜绝 cherry-picking；
3. **本体论立场明确**："与力场自洽"是第一设计目标（DII 是 MD 后处理工具，服务对象是模拟体系）；判例主动避开"力场与化学事实冲突区"；
4. **分层论证**：图 2 证明基团层、图 3 证明端到端层，两图是分层论证而非互相声称独立；
5. **信任漏斗顺序**：先证"正常"（常规一致性）→ 再证"独特"（判例差异）→ 性能 → 边界；
6. **性能不正面撞 InterMap**：InterMap 是性能上限参照，我们的叙事是"零推断 + 帧无关前提下的可行性能"，不作"最快"之争。

## 3. 逐图详述

### 图 1｜范式对比 + 架构总览（证明 C1）

- **A 面板（范式对比，Introduction 性质）**：两条路线的并排事实对比——
  - 左（现有路线）：坐标 → OpenBabel / RDKit 重建化学（推断键序/芳香/加氢，每帧重做，丢弃 tpr 化学信息）；
  - 右（我们的路线）：tpr 类型语义 → 零推断鉴定一次 → 逐帧几何；
  - 三行标注：零推断 / 帧无关 / 与力场自洽，各挂一个 claim。
- **B 面板（架构，Methods 性质）**：两段式管线（Reader → Identifier → Detector → h5/导出），**显式标出 Identifier 在轨迹循环之外**（帧无关的可视化位置）。
- **防御**：只画事实差异，不做"我们更好"断言——优势由后续图兑现。

### 图 2｜基团鉴定验证（核心图，证明 C2 + C3）

**2A 常规对齐（证明"正常"）**：
- 数据集：N 个体系（优先公开体系保证复现 + 自建体系补充），每体系 1 帧（标注：鉴定不随帧变，S3 补多帧证据）；
- **盲跑**：所有体系不预选，跑完才归类；
- **双指标报告**（修复关键）：
  - 对齐度：与 ProLIF 的逐基团/逐原子一致率（证明"没写错"）；
  - 真值符合率：所有不一致处落到外部化学事实仲裁，统计"谁更符合"（证明"即使不一致也是我们对"）；
- 预期结论："高对齐 + 不一致处真值符合率≈1"。

**2B 预注册判例（证明"独特"）**：
- 判例标准实验前注册："**力场类型与 SMARTS 推断存在已知分歧的官能团**"——Tyr CZ 双身份、肽键 N 受体、2,3-二氢噻吩式环（非芳香）、N3/n3、双键碳类型等；
- 呈现：表格（化学事实 / ProLIF / PLIP / DII / 谁对），每个判例标注**选入理由**；
- 防御：清单实验前定死、选入理由可复算、**主动避开已知力场与化学事实冲突区**（否则"零推断=零纠错"自爆）。

### 图 3｜端到端相互作用正确性（证明 C2 端到端层）

- **不声称"独立验证"**（几何判据不独立于基团）；改为**分层论证**：在图 2 基团对齐的体系上，比较端到端输出；
- 指标：occupancy 分布（箱线）、相互作用类型分布（堆叠柱）、时间序列形态；差异逐案化学仲裁；
- 亮点：展示"**基团层免疫的错误**"——肽键 N 受体、环判定错在 ProLIF 几何层才暴露，我们在基团层就免疫（图 2B 判例的端到端后果，形成 2→3 因果链）。

### 图 4｜性能与帧无关（证明 C3 工作流差异化）

- **主指标（三件套，同输入/同硬件/锁定版本）**：墙钟、峰值内存、检出量——对比 ProLIF（结构性重建成本）、PLIP（逐帧 OpenBabel，慢参照）、InterMap（性能上限，**不作胜负叙事**）；
- **帧无关**：鉴定耗时 vs 帧数线性图——**只做结构性说明，不对比**（承认工具不暴露分阶段，避免单边证据）；
- **消融**：two_pass / per_frame / per_tuple——标注**适用场景**（候选对数量、内存、轨迹长度），不是优劣排序（防"慢基线稻草人"）；
- 防御：Docker/conda 锁定环境 + 版本 pin（学 InterMap 的 commit 锁定做法）。

### 图 5｜应用案例：KRAS-RBD D927（价值展示）

- 端到端产出：8 类相互作用时间序列、占用率排名、相互作用网络；
- **验证性质**（防"截图不是验证"攻击）：D927 已知化学事实（3 芳香环 + 1 非芳香含硫环）在鉴定输出中的体现；与文献已知相互作用对照；
- 防御：数据可用性声明（轨迹可申请/公开）+ 辅以一条公开体系复现。

### 图 6｜适用域 + 可扩展路线 + 设计哲学（边界）

- 决策图：输入条件（tpr + 全原子 + Amber 家族）→ 可用；UA 力场 / 无 tpr → 不可用；
- **可扩展路线**（防"绑定是没做"攻击）：特征映射表是**唯一新力场接入点**——架构上已设计好，支持 CHARMM/OPLS 只是填表 + 验证的扩展工作；
- 设计哲学："读参数化判决 → 绑定力场是特性"。

## 4. 预注册协议（S2 全文内容，修复方案的灵魂）

1. **判例清单**：实验前定义 8–12 个 adversarial 判例，含选入理由；
2. **仲裁顺序**：化学事实（canonical SMILES / IUPAC / 文献）＞ 力场文档（rtp / GAFF 命名规则）＞ 工具共识——写死，不现场解释；
3. **指标定义**：对齐度 = 与参照工具的一致率；真值符合率 = 不一致处符合化学事实的比例——两个数分开报；
4. **案例分配规则**：2A 盲跑全体系、2B 预注册判例——禁止按结果调整归属；
5. **冲突区声明**：主动列出"已知力场与化学事实潜在冲突的官能团"，判例避开、单独进讨论。

## 7. 残余风险（诚实声明）

1. **判例真值的"模型争议面"**：芳香性/质子化定义有工具间模型差异——用无争议判例缓解，仍有边界案例；
2. **私有体系复现性**：KRAS-RBD 不公开——靠公开声明 + 公开体系辅助，无法完全消除；
3. **帧无关的"单边"性质**：参照工具不暴露分阶段——只能做结构性说明；
4. **力场绑定仍是硬限制**：可扩展路线缓解叙事，"当前只有 Amber"是事实；
5. **样本量与统计功效**：判例 8–12 个、体系有限——靠盲跑 + 多体系 + S1 定量对照提升说服力。
