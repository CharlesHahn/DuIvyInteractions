# 结果解读

`dii export` 将 h5 结果导出为 xvg / xpm / csv 三类文件。本文档说明每类文件的格式与含义，以及如何解读。

## 概览（打印到终端）

运行 `dii export` 时，会先打印该类型的概览：

```
===== Salt Bridge 概览 =====
类型:     salt_bridge
基团对数: 47
帧数:     101
时间范围: 0.0 ~ 1000.0 ps

Top 5 占位率:
  1. ARG210(3443-3451)···ASP211(3461-3463)  100.0%
  ...
```

- **基团对数**：该类型下所有候选基团对的数量
- **帧数 / 时间范围**：轨迹的总帧数与时间跨度
- **Top N 占位率**：占位率最高的 N 对（默认 5）。占位率 = 该对存在的帧数 / 总帧数，即该相互作用在整个模拟中出现的时间比例

## CSV 汇总（每对统计）

`<类型>_summary.csv` 以行-列为表格记录每对基团的汇总统计。仅包含占位率 > 0 的基团对。

| 列 | 含义 |
|:---|:-----|
| `pair_label` | 基团对标签（如 `ARG210(3443-3451)···ASP211(3461-3463)`） |
| `occupancy` | 占位率（0~1） |
| `avg_<metric>` | 活跃帧中该指标的均值（如平均距离，单位 Å） |
| `std_<metric>` | 活跃帧中该指标的标准差 |

示例：

```
pair_label,occupancy,avg_distance,std_distance
ARG210(3443-3443)···ASP211(3461-3463),1.0000,3.6200,0.0548
```

解读：`ARG210···ASP211` 盐桥占位率 100%，平均距离 3.62 Å，标准差 0.055 Å——说明该盐桥全程稳定存在且构象紧凑。

## XVG（时间序列）

xvg 是 GROMACS 标准时间序列格式，可用 DuIvyTools 或 Xmgrace 绘图。

| 文件 | 内容 |
|:-----|:-----|
| `<类型>_count.xvg` | X 轴为时间，Y 轴为每帧活跃的相互作用数量 |
| `<类型>_<metric>.xvg` | 每列一条曲线，为某个指标（如 distance、angle）在全部帧上的值 |

非活跃帧的指标为 NaN（图中表现为断点），需结合 existence 图判断。

## XPM（热力图）

xpm 是 GROMACS 标准矩阵热力图格式，行列构成矩阵，颜色表示值。

### existence 热力图

`<类型>_existence.xpm`

- **行**：基团对（pair），**列**：帧
- **颜色**：白色 = 该帧无此相互作用（No），蓝色 = 存在（Yes）
- 用途：快速查看各基团对在时间上的存在模式（连续/间歇/只在局部时间出现）

### π-堆积类型热力图

`<类型>_type.xpm`（仅 π-堆积）

- 三值颜色：白 = 无、粉 = T 型堆积、蓝 = 平行堆积
- 用途：区分 π 堆积的几何构型

## 基团对标签格式

各类型标签含义不同，用于在结构上定位相互作用的原子：

| 类型 | 标签格式 | 示例 |
|:-----|:---------|:-----|
| 盐桥/π-阳离子/疏水 | `残基名残基号(起原子-止原子)···残基名残基号(起原子-止原子)` | `ARG210(3443-3451)···ASP211(3461-3463)` |
| 氢键 | `残基名:供体原子(索引)-氢(索引)···残基名:受体原子(索引)` | `ARG210:NE(3443)-HE(3444)···ASP211:OD1(3461)` |
| 水桥 | `供体(D-H)···水(O)···受体(A)` | `ARG210:NE(3443)-HE(3444)···SOL:OW(5000)···ASP211:OD1(3461)` |
| 卤键 | `卤素供体···受体` | `D927:CL(10)···ASP211:OD1(3461)` |
| 金属配位 | `金属···配位原子` | `MG:MG(100)···ASP211:OD1(3461)` |
