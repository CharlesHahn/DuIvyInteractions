# 疏水基团识别定义

> 状态：定义定稿

---

## 1. 化学定义

疏水性 = 不能与水形成氢键 = 周围没有电负性原子。

疏水相互作用源于熵变（疏水效应），不是吸引力。观察到的疏水接触随距离指数衰减。

---

## 2. 疏水原子判定规则

一个原子是疏水原子，当且仅当同时满足以下两个条件：

**条件 1**：原子是碳（element == 'C'）。

**条件 2**：所有邻居原子都是碳或氢（neighbor element ∈ {'C', 'H'}）。

```
对每个原子 a：
  if a.element != 'C' → 非疏水
  if 任何邻居的 element ∉ {'C', 'H'} → 非疏水
  else → 疏水原子
```

### 2.1 判定示例

| 原子 | 邻居 | 疏水? | 原因 |
|------|------|-------|------|
| 甲基 C | 3H + 1C | ✅ | 邻居全是 C/H |
| 亚甲基 C | 2H + 2C | ✅ | 邻居全是 C/H |
| 苯环 C | 2C + 1H | ✅ | 邻居全是 C/H |
| 羰基 C | 1O + ... | ❌ | 有 O 邻居 |
| 醇 C | 1O + ... | ❌ | 有 O 邻居 |
| 酰胺 C | 1N + 1O | ❌ | 有 N/O 邻居 |
| 腈 C | 1N + ... | ❌ | 有 N 邻居 |
| 氟代 C | 3F + 1C | ❌ | 有 F 邻居 |

### 2.2 与芳香环的关系

芳香环中的碳原子（如苯环 C）也满足疏水条件（C + 邻居全是 C/H）。

**在基团识别阶段不排除芳香环原子**。疏水基团和芳香环基团是独立识别的，允许原子重叠。

**去重在相互作用检测阶段处理**：如果两个芳香环已经形成 π-π 堆积，则移除它们之间的疏水相互作用（避免重复计数同一物理接触）。

## 3. 基团数据结构

每个疏水原子生成一个 Group：

| 字段 | 说明 |
|------|------|
| group_type | `"hydrophobic"` |
| atoms | 单个碳原子的 AtomData |
| metadata | 空（无额外属性） |

---

## 4. 相互作用检测阶段去重规则

疏水基团识别不排除芳香环原子。去重在相互作用检测阶段执行：

**规则**：如果两个芳香环已经形成 π-π 堆积相互作用，则移除这两个环的原子之间的疏水相互作用。

**原因**：π-π 堆积已经包含了疏水接触（芳香环之间的 van der Waals 力）。如果同时报告 π-π 堆积和疏水相互作用，会重复计数同一物理接触。

**实现**：在相互作用检测阶段，先检测 π-π 堆积，再检测疏水相互作用，最后移除与 π-堆积重叠的疏水接触。
