# 基团识别规则

基团鉴定阶段从 tpr 的原子类型、键合图、电荷和显式氢原子识别出可参与相互作用的化学基团。本文档列出各基团的判定规则与可行性依据，供理解工具行为与验证结果。

## 基团类型全集（GROUP_TYPES）

工具可识别的基团类型（core/constants.py）：

| 基团类型 | 参与相互作用 |
|:---------|:------------|
| `H_donor` | 氢键、水桥 |
| `H_acceptor` | 氢键、水桥 |
| `aromatic_ring` | π-π 堆积、π-阳离子、卤键（π 受体） |
| `charged_positive` | 盐桥、π-阳离子 |
| `charged_negative` | 盐桥 |
| `halogen_donor` | 卤键 |
| `halogen_acceptor` | 卤键 |
| `metal` | 金属配位 |
| `metal_binding` | 金属配位 |
| `water` | 水桥 |
| `hydrophobic` | 疏水 |

## 逐基团可行性矩阵

| 基团 | 所需化学特征 | tpr 中证据 | 确定性 |
|:-----|:------------|:-----------|:-------|
| **芳香环**（π-π/π-阳/卤-π） | 芳香环 | 类型 `ca/na/nb/cp/cg` → 图论环检测（边删除+BFS+稠合去重）→ 环内全芳香；可选键序 func=4/5 与平面性交叉验证 | 高 |
| **H 键供体** | D–H（D=N/O/S/F） | D–H 键条目显式存在（全原子，Bond+Constraint 合并）+ q(H)>0 | 100%（零推断） |
| **H 键受体** | 孤对可用 | 类型规则表（`o/oh/os/nb/n/f`…）+ H 计数（`nb` 无 H 必为受体）+ 电荷为负验证 | 高 |
| **盐桥** | 形式电荷对 | 蛋白残基名字典（LYS/ARG/ASP/GLU/HIP 编码质子化态）；配体靠类型+H 计数 | 蛋白 100%，配体高 |
| **疏水** | 非极性 C/S/X | 类型集合（`c3/c2`…）+ 无极性取代 | 高 |
| **卤键** | σ-hole 卤素 | 卤素类型（`f/cl/br/i`）+ 邻接碳类型区分芳香卤/烷基卤 | 高 |
| **金属配位** | 金属中心 | 元素/类型 + 电荷（本项目 Mg²⁺）；用原子序数（不依赖类型名） | 100% |
| **水桥** | 水分子 | 残基名 SOL/HOH + OW/HW 原子名 | 100% |

## 识别方法要点

### 芳香环检测

1. 从类型名确定强芳香原子（`STRONG_AROMATIC`）
2. 图论环检测（边删除 + BFS），找环
3. 稠合环冗余去除（`_deduplicate_aromatic_rings`）
4. 过滤：环内 n-1 个原子为芳香（`COMPATIBLE_TYPES` 在强制下可参与共轭）
5. 可选：键序 func=4/5 与平面性交叉验证

已实证：D927 找到 3 个芳香环 + 1 个非芳香含硫环（2,3-二氢噻吩式稠合杂环，C22=C23 双键非芳香噻吩）；RBD 27 环（Pro×9+Tyr×11+His×3+Trp×2+Phe×1）全部化学正确。

### 供体判定

判据 = D-H 键（Bond+Constraint 合并）+ q(H)>0。因 N-H 键在 tpr 的 Constraint 段（非 Bond 段），**必须合并两者**。已实证：RBD 263 个供体 H 电荷全部 +0.19~+0.45，无 q(H)≤0。

### 蛋白带电基团

由残基名字典编码质子化态：LYS（+）、ARG（+）、ASP（−）、GLU（−）、HIP（组氨酸正电态）。配体带电基团靠类型 + H 计数判断。

## 类型名坑（影响判定的歧义）

- **`C` 双身份**：主链羰基碳 vs Tyr CZ 芳环碳。需"环内 ≥4 个强芳香邻居"升级为芳香。
- **`N3` vs `n3`**：蛋白正电氨基 vs GAFF 中性氨基，大小写不同义。
- **`CA` 跨力场不同义**：amber=芳香碳，GROMOS=α 碳。必须经特征映射表。
- **N-H 键在 Constraint 段**：供体识别必须合并 Bond + Constraint。

## 支持边界

- 全原子力场（Amber 系）依赖显式氢原子；联合原子力场（GROMOS 无显式 H）供体鉴定失效，声明不支持
- 键序缺失鲁棒：即使 tpr 不保留键序，类型名已编码芳香性，判定可靠
